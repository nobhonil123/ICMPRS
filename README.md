## ⚠️ Important Disclaimer

All performance metrics reported in the paper (97.4 % accuracy, AUC 0.987) are evaluated on **synthetic benchmark data** generated by the same parametric engine used for training. They reflect **controlled architectural capacity**, not clinical screening performance.

The five Indian-specific biomarkers (RCA, NRE, DPLD, AJHI, BSV) are formulated here as **testable hypotheses** grounded in phonetic and motor-science literature. Their discriminative validity has **not** been confirmed on real patients. IRB-approved prospective validation is the immediate next step.

---

## Overview

ICMPRS is a parametric cohort-generation framework that synthesises voice, handwriting, and gait feature vectors for 1 995 participants whose statistical profiles are anchored to published Indian clinical measurements. Five culturally motivated candidate biomarkers are formalised:

| ID | Name | Modality | Linguistic/Cultural Basis |
|----|------|----------|--------------------------|
| RCA | Retroflex Consonant Articulation Degradation | Voice | Hindi retroflex consonants |
| NRE | Nasalization Residual Energy | Voice | Hindi phonemic nasalisation |
| DPLD | Devanagari Pen-Lift Dynamics | Handwriting | Shirorekha (headline) pen-lifts |
| AJHI | Akshar Junction Hesitation Index | Handwriting | Samyukt akshar conjunct strokes |
| BSV | Barefoot Stride Variance | Gait | Barefoot locomotion on varied terrain |

The **CGMS** (Confidence-Gated Multimodal Screening) classifier pairs a dual-stream RBF-SVM + Random Forest with:
- **ACG** — Adaptive Confidence Gating (quality-aware fusion weights)
- **CMCC** — Cross-Modal Consistency Check (referral safety gate)

## Quick Start

### 1. Install dependencies

```bash
git clone https://github.com/nobhonil123/ICMPRS.git
cd ICMPRS
pip install -r requirements.txt
pip install -e .          # optional: install as package
```

### 2. Generate the synthetic cohort

```bash
# Primary cohort (seed=42, n=1995) — matches the paper exactly
python scripts/generate_dataset.py

# Or use the CLI entry point after pip install -e .
icmprs-generate --n 1995 --seed 42 --out data/icmprs_features.csv
```

### 3. Reproduce all paper results

```bash
python scripts/run_evaluation.py --data data/icmprs_features.csv
# Outputs: results/table_VII_fold_stability.csv
#          results/table_XI_snr_ablation.csv
#          results/summary_metrics.json
```

### 4. Cross-dataset evaluation (Table XII)

```bash
# Requires UCI Parkinsons Voice dataset and mPower access
# See scripts/cross_dataset_eval.py for download instructions
python scripts/cross_dataset_eval.py \
    --uci  data/uci_parkinsons.csv \
    --mpower data/mpower_voice.csv
```

### 5. Programmatic API

```python
from icmprs.generator import ICMPRSGenerator
from cgms.pipeline import CGMSPipeline

# Generate cohort
gen = ICMPRSGenerator(seed=42)
df  = gen.generate(n=1995)

# Build and evaluate CGMS
pipeline = CGMSPipeline(
    voice_features=gen.FEATURE_NAMES_ACOUSTIC,
    movement_features=[c for c in gen.feature_columns
                       if c not in gen.FEATURE_NAMES_ACOUSTIC],
    seed=42,
    snr_db=20.0,
)
results = pipeline.evaluate_cv(df)
print(f"Accuracy: {results['mean_accuracy']*100:.1f}%")
print(f"AUC:      {results['mean_auc']:.4f}")
```

## Reproducing Paper Results

All results can be regenerated from the provided scripts **without modification**:

| Paper Result | Command / Script |
|---|---|
| Table VI — Architecture comparison | `run_evaluation.py` |
| Table VII — Fold-wise stability | `run_evaluation.py` |
| Table VIII — Ablation | `run_evaluation.py --ablation` |
| Table XI — SNR noise sweep | `run_evaluation.py` |
| Table XII — Cross-dataset (UCI, mPower) | `cross_dataset_eval.py` |
| Fig. 2 — SNR curve | `notebooks/03_results_figures.ipynb` |
| Fig. 3 — ROC curves | `notebooks/03_results_figures.ipynb` |
| CAG, distribution-shift bound | `run_evaluation.py` (printed to stdout) |

**Inference latency** (Table V) was measured on a **Raspberry Pi 4B** (ARM Cortex-A72, 1.8 GHz, **2 GB RAM** configuration). Measurements on other hardware will differ.
